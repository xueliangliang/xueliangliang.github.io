How?

How was this website built? I followed some simple principles and made use of many existing open-source tools.

The principles are:

  • Other People's ____

    • I used many other people's libraries and tools.

  • KISS Principle

    • Keep it simple and stupid. I separated the website into different modules and layers; each module and layer has a simple responsibility. I used Gulp.js to manage the packaging and build process.

  • Kill two birds with one stone

    • Before this assignment, I had not used Gulp.js. I took the opportunity to learn how to use it to manage an HTML front-end workflow.

  • Think Outside the Box

    • To think outside the box, we need to know where the box is. Initially, I wanted to use a traditional website to display all the information. Then I happened to visit the TimelineJS website and found that a timeline would present my portfolio more informatively. That is how the current visual design came about.

The tools used:

  • SASS
  • TimelineJS
  • SWIG Template
  • PhotoPile
  • Gulp.js
